# Linux ソース配布の確認項目

導入手順は [START-HERE-LINUX.md](../START-HERE-LINUX.md) を参照してください。

- Ubuntu 24.04 LTS デスクトップ x86_64 の通常ユーザーで導入する。
- 既存の保存先を上書きせず、空白・日本語を含むパスでも起動・停止を確認する。
- 固定依存物のハッシュ、Deno のロック、生成 MCP 設定を確認する。
- 保存先 0700・ファイル 0600 と、鍵の欠落・改変やリンクに対する拒否を確認する。
- QR 表示は本人の端末で確認し、QR・PIN をログや公開の場所へ残さない。
- [自動テスト](TEST-STATUS.md)、配布許可リスト、秘密情報検査を確認する。

Windows の認証ファイルを Linux へ移す方式は提供しません。ソース配布に `profile-key.bin`、プロファイル、履歴、依存物バイナリを含めません。実アカウントの確認は [LIVE-CHECKS.md](LIVE-CHECKS.md) を参照してください。
