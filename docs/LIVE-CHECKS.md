# 実アカウントでの確認

自動テストは合成データを使用します。実アカウントでの認証・配信・復旧の結果は保証しません。

必要な確認は、利用者本人が自分の端末とアカウントで実施します。

1. 本人が QR と必要時の PIN を使ってログインする。
2. `bridge_status` と、通常 LINE・OpenChat の一覧を確認する。
3. 自分が選んだチャットの不透明な `chat_ref` を使い、取得可能なメッセージを確認する。
4. 実送信を確認する場合は、本人が宛先と本文を決め、LINE 側でも結果を確認する。
5. 結果不明の送信は UUID を変更して再送しない。

QR・PIN・トークン・鍵・チャット名・本文・個人の利用件数・プロファイルを、Issue やログへ添付しないでください。報告にはバージョン、OS、再現手順と伏せたエラーコードを使います。
