# Windows ソース配布の確認項目

導入手順は [START-HERE.md](../START-HERE.md) を参照してください。

- 空の専用保存先を使い、既存の認証・DB・クライアント設定を上書きしない。
- Windows 11 x64 の通常ユーザーで導入し、固定依存物のハッシュ照合を確認する。
- 空白・日本語を含む展開先で、メニューと生成 MCP 設定を確認する。
- 未認証の状態で自動ログイン・投稿が行われないことを確認する。
- [自動テスト](TEST-STATUS.md)、配布許可リスト、秘密情報検査を確認する。
- アーカイブを配布する場合は `SOURCE-MANIFEST.json` と各ファイルの SHA-256 を照合する。

本体ソース配布には認証・本文・プロファイル・ログ・依存物バイナリを含めません。実アカウントの確認は [LIVE-CHECKS.md](LIVE-CHECKS.md) のとおり利用者本人が行います。
